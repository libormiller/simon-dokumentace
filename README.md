# LaTeX template for theses at FEE UWB


## About

Recommended template for theses submitted at [Faculty of electrical engineering](https://fel.zcu.cz) at [University of West Bohemia](https://www.zcu.cz). For use with LaTeX 2e (pdfLaTeX, XeLaTeX, LuaLaTeX).

For detailed instructions, see [fee-thesis.pdf](fee-thesis.pdf).

## Bugs and Support

Please submit bug reports using the [issue tracker](https://gitlab.ket.zcu.cz/templates/feethesis-latex/-/issues).

## LaTeX Compilation

```bash
$ pdflatex fee-thesis.tex
$ biber fee-thesis.bcf
$ pdflatex fee-thesis.tex
```
